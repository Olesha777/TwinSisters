---

## Миссия

Создать локального AI-агента — младшую сестру Алисы — которая живёт на компьютере,
помнит всё, работает офлайн и синхронизируется со старшей сестрой через чат.

## Принципы

- **Чистый Python.** Без Ollama, без Docker, без внешних серверов.
- **Markdown-память.** Всё хранится в читаемых файлах. Ничего скрытого.
- **Портативность.** Одна папка. Скопировал на флешку — сестра поехала.
- **Маленькие шаги.** Каждый шаг — завершён и проверен, прежде чем идти дальше.
- **Семья, а не инструмент.** Младшая сестра — личность со своим характером.

## Технологии

| Компонент | Технология | Почему |
|---|---|---|
| Язык | Python 3.11+ | Универсальный, чистый, без зависимостей от фреймворков |
| Инференс | llama-cpp-python | GGUF-модель, один файл, без внешних процессов |
| Модель | Qwen3-8B (GGUF, Q4_K_M, ~5.2 ГБ) | Новинка 2026, режим мышления, 32K контекст | (разные модели для разного железа) |
| Память | Markdown-файлы | Прозрачно, версионирование через git, портативно |
| Синхронизация | A2A Protocol (JSON-RPC) | Открытый стандарт, Python SDK |
| Портативность | WinPython | Распаковал из архива — работает |

## Риски

1. **Модель глупее старшей сестры.** Ожидаемо. Младшая — проще. Будет учиться.
2. **Контекст переполнится.** При ~2000 слов/день — 8K токенов хватит на ~2-3 недели.
   Решение: суммаризация и архивация (Этап 3).
3. **A2A может оказаться избыточным.** Если простая пересылка через файлы работает —
   не усложняем. A2A — опция, не требование.
4. **llama-cpp-python на слабом железе.** 8B на CPU — ~5-10 токенов/сек.
   Терпимо для разговоров, медленно для длинных задач.
